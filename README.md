# CyberSaathi

### Pause. Check. Stay safe.

CyberSaathi is an intelligent digital safety
platform being developed to help people identify
suspicious messages, phishing links and online scams.

## Project Goal

To make digital safety easier to understand through
explainable cybersecurity analysis.

## Technology Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite (planned)

## Current Development Status

- Flask application foundation
- Homepage and responsive design
- Project architecture
- GitHub version control

Message and URL detection features are under development.

## Running Locally

1. Clone the repository.
2. Create a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   python run.py

5. Open http://127.0.0.1:5000
